# 40 案例自由对话评测集

2026-10-10 已完成 `freechat-v3.0-20261010` 的数据准备与检查：40 案例、244 轮，全部是 `free` 入口。餐厅、购物、自我介绍和听辨请求属于学生自选练习，不因此变成 Mission。当前状态是 `prepared_not_executed`，没有调用真实豆包或 Judge，没有模型得分。

完整 CSV、审阅工作簿和规范 JSON 单独交付。仓库只保存[无对话正文的清单](freechat-eval-manifest.json)、准备格式校验器和合成测试，不提交上传的学生对话内容。

## 完善内容

- 每案补齐开场事实、首轮推断的软目标、初始状态、未知信息及证据来源。软目标可改变，不是强制课程任务。031、034 不从第二轮倒推初始主题，033 不凭参考回复制造初始猫兴趣。
- 初始完整画像、历史会话、`known_items/new_items` 未提供，显式保留 unknown。007、015、016 仅根据首轮已知语言标注声明最小场景假设；它们是测试条件，不是真实授权画像或掌握证明。
- 每轮保留原始用户输入和参考回复，另列规范必须满足、禁止行为、关键失败、语言支架、主动承接与总结范围。原始 CSV 的 20 列逐格保留，新增 20 个规范字段；工作簿保留 12 个有效原始列。
- 语言预期只从初始声明条件和截至本轮的学生输入推导。普通正确中文、参考回复或未来回合不构成掌握证据。案例 037 的茶已知自述只能从第 11 轮使用。
- 回放历史只包含实际此前 Kai 回复与学生输入。参考回复用于评审，不能作为待测模型前文或实际输出。固定学生脚本测试特定上下文行为，不是实际自然互动的完整记录。

## 与当前策略对齐

继续使用 `kai-content-v3` 的原十维、0/1/2 和权重。原五维的 9 条 `learning_guidance N/A` 不直接映射成十维豁免。纯社交的 progress 评自然承接、尊重只聊天或结束，不因“没教学”扣分。本集无预设十维 N/A，安全门槛不变。

中文优先，未知画像默认必要短英文；adaptive 只允许已知或易懂部分省英文，新表达仍要必要支持。精确单句输出请求仅约束该轮。共享 `kai-reply-v2` 预算不变：最多两句中文及必要英文，36 汉字、24 英文词、48 合计单位、180 字符，一个主要问题／任务、一个新点和一个短例。

40 个结尾已统一为短口头收束与现有 Web 总结。拼音长词表、任意新词卡和未知初始内容的“新学／复习”标签不作为当前 POC 的硬要求。总结只能引用实际发生且有来源的内容；没有受支持的卡片或练习证据时如实显示交流小结，不生成虚构成果。

34 个主动承接信号都来自学生话语，不是真实 idle、沉默或定时器事件。听辨／发音案例没有实际音频，不能报告实听成绩，也不能把本集缺音频说成整个产品不支持语音。

## 检查结果与使用

编号、轮次、原文保留、目标来源、前文边界、初始假设来源、语言状态和评分版本均已检查。现有计数器对参考文本提示 27 条超预算、62 条语言表面提示、5 条问题数提示；这些类别可重叠，只针对作者参考文本。

67 条语言／问题数提示已逐条复核并附处理。中文词嵌入英译、引语、同一个问题的选项可能是计数提示；同时问形式与主题则已改为一次一个问题。不能把这些提示当作真实模型成绩，或用标点计数证明翻译、新点和任务语义合格。

```bash
npm run eval:dataset:check -- /absolute/path/ask-kai-freechat-eval-v3.json
```

准备格式校验不发网络请求、不生成回复、不打分。它检查重复／断号、原文一致、参考／未来前文泄漏、未知画像来源、语言状态重算、评分漂移和伪造执行结果。当前 JSON 不能直接交给 `eval:content`；后续任务才收集实际回复、保存模型／提示词／Judge 版本并适配原十维评测器。

本轮完成数据准备。真实语速、插话、字幕播放、听辨及发音仍属于真实音频和设备验收；这 40 案例不覆盖全部三个入口的产品验收。
