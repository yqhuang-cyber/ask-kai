# 上下文快照、来源与更新确认

2026-10-12。收尾Task05-02实现：`TeachingSession.contextSnapshot()`经纯函数统一组装版本化上下文，返回不可变的指令、哈希、语言状态、教学建议和来源。服务器暂存待确认与已确认快照，模型指令和完整状态不进入普通诊断导出。

本项保持原指令文本和原回复／取消边界。三个入口的初始指令与改造前按字节一致；语言选择、教学动作、回复预算尚未调整。策略改动在后续子任务单独实施。

初始快照随会话创建送给豆包。新的最终学生输入产生新状态版本，仅记录为排队；现有回复边界发送一次不可变快照。等待确认期间若又有新输入，正在确认的快照不变，后续边界再发送最新版本。错误版本、重复确认、已关闭连接的迟到回调不能覆盖新状态。

诊断增加 `context.queued`、快照哈希、上下文策略版本、后续输入作用范围及确认忽略原因。每条回复在可见开始通知处固定已确认快照，另记当前服务器状态版本。旧决策与本轮归属不匹配继续标记；这些元数据不能证明模型内部采用的快照、真实生成起点、内容遵守或客户端播放。

保留 `context.requested`／`context.applied`内部名称用于源码和记录关联，正文用“上下文更新确认回执”。普通全双工仍不统一等待后台确认后才回答，不追溯重判旧回复；实时流、打断和撤权沿用原合同。

私有快照仅在当前服务器会话内使用。导出只允许64位十六进制哈希、固定枚举、数字版本及已有匿名归属引用，不导出指令、学生原话、画像值或原始音频。
